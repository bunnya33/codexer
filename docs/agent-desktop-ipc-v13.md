# 官方桌面 v13 同步与空闲资源增长

## 2026-11-16 现场结论

本机安装的 Qt Agent 0.2.41 在没有 Agent 任务、没有文件预览请求时，区间 CPU 为整机的约 5.4%–6.2%（12 个逻辑 CPU），主要由后台工作线程消耗。采样中 Agent 工作集在约 245–375 MiB 之间波动，后续也观察到约 413 MiB；私有提交同时上涨。此处统计 Agent 自身进程，未把其 Codex app-server 子进程或官方桌面进程计入。

只读线程栈与 IPC 帧元数据定位到以下循环：

1. 官方桌面发出 `thread-stream-state-changed` v13 快照，单帧约 1.84 MiB。
2. Agent 只接受 v11，抛出 `unsupported-desktop-ipc-version`。
3. 通用异常处理立即取消、重新订阅同一个会话。
4. 官方桌面再发送完整快照，Agent 再次拒绝；循环即使没有用户操作也会继续。

现场同一会话快照 revision 快速递增，接收缓冲反复积累到约 62 MiB。大量重复传输、JSON 解析、缓冲分配与堆内存保留能解释当前持续 CPU 和内存压力，但不能据此认定所有增长都是不可达对象泄漏，也不能归因另一台设备此前的 8 GB 现场。

整个检查未重启、安装或替换运行中的 Agent，也未改变官方桌面的会话内容或启动模型任务。诊断仅记录函数名、结构字段、协议版本、字节数和资源计数；未把会话正文写入报告。

## 修复行为

- Qt 后台接受已核对的 v11、v13 快照及增量补丁。官方本机客户端的 v13 定义仍使用 `conversationState`、`revision`、`baseRevision`、`patches`；`acceptedTextChanges` 为官方文本缓存提供附加提示，正文仍由常规状态补丁更新。Agent 直接从更新后的状态生成展示内容。
- 本机使用的发送、停止、设置及审批方法版本保持原有定义；同步广播的版本与各请求方法的版本彼此独立。
- 未支持的协议和无效快照停止订阅、清除原始状态，保留拒绝原因。周期刷新和 owner 重新发现不会立即重订阅同一条被拒绝的流。
- 丢失或无效补丁最多自动请求一次新快照。再次失败后同样停止订阅，避免另一种无限循环。
- 自动模式沿用有界的只读 RPC 回退；回退读取本身不调用 `thread/resume`。仅桌面模式将已有会话标为暂不可操作。重新打开桌面传输后可以重新尝试协商。
- 原有单会话 32 MiB、全部会话 128 MiB 的原始状态估算预算继续生效；它们不是进程总内存上限。

## 验证

基于 `main` 的 `a8bc7bc` 修改；Windows 使用 Qt 6.8.3 / MSVC，实际编译 `CodexerAgent` 和 `CodexerNativeTests` 成功。后台测试 **140 通过、0 失败、3 跳过**；跳过项需要显式启用外部文件传输基准或真实隔离写入探针。新增回归覆盖 v13 canonical 文本补丁、v11/v13 发送路由、未知协议和无效快照的自动/仅桌面模式，以及补丁恢复次数上限。

独立 Qt 只读探针使用已在现场观察到的 owner，接收当前官方桌面真实 v13 快照。为避开旧 Agent 循环对 owner 发现的干扰，探针在本地提供该发现结果，其余消息连接真实 `codex-ipc`。实际收到 1 个约 2.19 MiB 快照，canonical 历史 7 轮；原始状态估算 4.37 MiB，近期两轮有界展示约 67 KiB。兼容状态为 true，重新订阅次数为 0。本次三秒观察窗口未收到真实增量补丁；增量内容与发送行为由隔离原生测试验证，未向真实会话发送消息。

另用相同预编码的 1,902,740 字节合成快照，对比修改前 `native_io.cpp` 与修复后的原生传输，各观察约三秒：

| 指标 | 修改前 | 修复后 |
| --- | ---: | ---: |
| 完整快照次数 | 345 | 1 |
| 取消订阅次数 | 344 | 0 |
| 进程累计 CPU 增量 | 2,921.875 ms | 15.625 ms |
| 单核 CPU 比例 | 96.62% | 0.52% |
| 接收后兼容状态 | false | true |

该基准仅含原生传输和同进程模拟发送端，不含 UI、服务同步、其他会话和 Codex 子进程，不代表整个 Agent 更新后的资源占用。修复后会保留一份可用的有界原始状态；基准私有提交为 19.41 MiB，修改前为 15.16 MiB，因此不能用这个基准宣称整个 Agent 的内存已降到某个数值。

诊断记录保存在忽略目录 `.local/agent-idle-audit-20261116`。随后已完成 macOS arm64 0.2.42 原生编译、回归和 DMG／ZIP 校验；本机替换仍待解锁，详见 [macOS 构建](mac.md) 与 [验证记录](validation.md)。更新后的长期空闲内存还需安装后另行采样。
