# 会话与项目文件下载性能

文件链路为 PC Agent → Relay → 手机或浏览器。Relay 不保存普通文件副本；PC 需在线且保留原文件。Relay 没有固定的字节速率限制，既有全局 4 路、每设备 2 路下载及请求频次保护继续有效。

## 2026-11-14 已确认的开销

对同一份 13,047,285 字节 IPA 做 Qt 原生回环测试：经过真实 WebSocket、文件读取和 250ms 后台定时器，50 个 256 KiB 分块之间统一增加 30ms 间隔，关闭无关维护以单独测量调度。修复前总计 12,481ms，修复后 1,951ms，约 6.4 倍；直接读取和 Base64 编码整份文件只需 39ms／33ms。重组文件的 SHA-256 均为 `154f68dd2c2ab4ec79b8558dbeb801341dc39977458230fa1457917d5efc8732`。这说明原有逐 tick 排队是确定的开销，不代表手机公网下载会固定提升 6.4 倍。

真实慢速下载期间采样旧 Agent，2,182 份工作线程栈中 1,906 份停在 `Service::tick → watch → Desktop::call → waitFor`，约占 87%。运行时刷新等待也会阻塞原队列。Mac 浏览器下载这份 IPA 时，87.98 秒仍未完成，261.34 秒观察时已完成；轮询间隔较长，只有完成区间，没有精确时长。既有 Relay 静态 1 MiB Range 测试约 0.10–0.40 秒，只覆盖 Relay 到 Mac，不能代替 Agent 链路或手机测速。

Base64 仍增加约三分之一的传输体积，但本次编码耗时不是主要阻塞；暂时沿用共享协议，避免把未经验证的协议改造作为本次修复。

用户完成 Mac 钥匙串授权并更新服务器后，`/health` 确认为 Relay `0.3.64`，原生窗口及状态确认 Qt Agent `0.2.39` 已连接。Mac 浏览器通过同一个会话文件链接三次下载完成，完成观察上界分别为 20.43／10.96／4.71 秒；前两次观察间隔较长，不能将上界当成精确耗时或取均值。第三次在 3.30 秒仍下载中、4.71 秒观察完成，能确认改善但不能据此承诺手机吞吐。网页在交给系统保存前核对完整响应大小，本次未取得浏览器保存路径做 SHA-256。Agent 本进程累计（含前置探测）排队最大 6ms、单块读取／编码最大 9ms，没有再次出现原先的数百毫秒调度等待。

重启后旧文件引用需要重新加载对应历史页；同步历史期间曾触发 HTTP 请求频次保护，另一次浏览器下载事件等待也超时，两次均不计入有效测速。后续使用文件弹窗的完成状态轮询，三次有效下载均成功。请求频次保护未调整；大量历史请求与单次文件传输的字节速度应分开判断。

## 修复与版本

- Qt Agent `0.2.39`：会话文件和项目文件的只读请求进入有界独立队列，用事件循环立即调度；即使后台运行时调用正在等待，也可读取分块。每次最多处理 2 个请求，8ms 为批次调度预算，队列最多 32 项。修改状态的命令仍按原队列串行执行。暂停、断线和停止会清理读取队列，旧连接代次的请求不会发送。
- Relay `0.3.64`：普通会话／项目下载最多同时预取 2 个 256 KiB 分块，按文件偏移顺序写出，降低逐块往返等待。预取上限 512 KiB，另有 Base64／JSON 及当前写出块的内存开销；客户端取消、写出失败或分块异常会取消剩余请求并回收读取协程。保留文件版本、大小、块长度、目录和授权检查，以及 `0.3.63` 的 Range／If-Range／HEAD 行为。

两项兼容原协议，可以分别升级；同时更新才能取得两部分收益。iOS build 5／现有兼容 Android 客户端无需为本次性能修复重新打包。Relay 更新包由本机准备，远程更新由用户完成，本机只读核对其版本；未核对远程二进制摘要。Mac Agent 的安装与连接状态见 [验证记录](validation.md)。

## 后续测速与定位

选择同一个文件、设备、网络和入口，对比更新前后至少三次下载，记录文件字节数、开始／完成观察时间及失败情况；有轮询间隔时保留上下界。手机 Wi-Fi 与蜂窝网络分别测量，避免将 Mac 浏览器结果当成手机结果。完整文件需核对大小或 SHA-256；同时验证取消、重试和断点继续。

Qt 状态文件的 `fileTransfers` 汇总当前进程的请求数、读取字节数、排队与读取／编码耗时总和及最大值。Relay 管理指标增加 `transport.fileReadRoundTrip` 和 `transport.fileReadErrors`。对比同一次下载前后的增量：Agent 排队高时检查后台调度；读取／编码高时检查磁盘与本机负载；Agent 两项都低但 Relay 往返高时检查 PC 上行、代理和 PC 到 Relay 网络；两侧都低但客户端仍慢时，再检查 Relay 出站及手机链路。指标只记录汇总耗时／计数，不包含路径、内容或凭据。

原生基准为显式启用的测试，默认跳过，避免普通回归依赖本机 IPA：

```sh
CODEXER_FILE_BENCHMARK_PATH=/absolute/path/to/file.ipa \
CODEXER_FILE_BENCHMARK_DELAY_MS=30 \
CODEXER_FILE_BENCHMARK_LABEL=after \
CODEXER_FILE_BENCHMARK_REPORT=/absolute/path/to/report.json \
apps/agent-qt/build/CodexerNativeTests fileDownloadBenchmark
```

本轮诊断在 Git 忽略的 `.local/download-diagnostics/20261114-acceleration`，构建、竞态检查与硬件验收边界见 [验证记录](validation.md)。
