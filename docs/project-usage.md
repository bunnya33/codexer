# 项目用量与并行会话数量

服务器 0.3.43 的 Web 控制端、Agent 0.2.29 和共享控制界面支持项目用量。会话标题下方保留项目与状态，新增项目累计 Token 和美元预估；点击统计可查看计数覆盖、各模型的输入、缓存命中及输出。

## 统计范围

以当前设备的完整项目目录为范围，包括已归档和未加载到实时预览的会话，不受搜索结果、30 个实时会话或已加载历史页数影响。未归类会话单独汇总，其他设备和项目不混入。已删除、不在当前目录的会话不包含在内。

Agent 从配置的 `codexHome`（默认 `~/.codex`）中选择数字版本最新的 `state_N.sqlite`，以短连接只读查询会话累计 `tokens_used`。逐会话与实时累计计数、本地 `usage.sqlite` 的轮次记录取最大值，再合计项目总量；不同数据源不能相加，以免重复计算。轮次记录按会话和轮次 ID 更新，重复通知、重连和重新打开会话不会重复累计。

每 5 秒刷新累计统计，有变化才发布目录。查询使用前向游标，不加载历史正文、不调用模型，也不通过恢复会话获取写入权。索引未知或不可读时，已有实时计数和轮次记录仍可提供已知下限；缺少累计计数用 `≥` 标记，全部未知时显示待同步。统计失败不阻止原有目录和指令同步。

## 美元预估

费率为 [OpenAI 官方 API 单价](https://developers.openai.com/api/docs/pricing) 的 **2026-11-08** 快照，以美元／百万 Token 保存。按 Standard 速度、短上下文的等值费用计算：

```text
((输入 - 缓存命中) × 输入单价 + 缓存命中 × 缓存单价 + 输出 × 输出单价) / 1,000,000
```

推理 Token 已包含在输出中，不重复收费。按记录中的精确模型 ID 匹配，仅允许去掉日期快照后缀；未知模型不套用相似模型价格。当前没有足够缓存写入保留时长信息的记录不计价。价格只在本地代码中计算，不额外向 OpenAI 上传用量或请求账单。

历史累计计数并不一定附带模型或输入／缓存／输出明细。这些 Token 保留在项目总量中，金额仅计算已有可计价明细的部分，并标为「部分预估」；完全没有明细显示「费用待统计」。小于一美分且大于零的金额显示 `<$0.01`。详情同时列出缺少计价明细的 Token 数。

该金额不是 ChatGPT/Codex 订阅实际扣款，也不包含速度、长上下文、地区、工具费用及折扣。模型或官方费率变化时，应核对官方页面后更新 `packages/client-shared/src/project-usage.ts` 的精确映射和日期；未知模型继续保留待统计。

## 单次回复费用（服务器 0.3.44）

正常完成的回复，在底部「已完成」后显示本次美元预估。只使用该轮已记录的模型和输入／缓存命中／输出明细，复用上面的官方费率与计算方法；不按当前模型回算历史，不用项目总量代表这一轮。金额保留四位小数，小于 0.0001 美元的正数显示 `<$0.0001`，以保留小额回复的差异。

缺少用量时显示「本次费用待统计」，缺少模型或无法计价时显示「本次费用暂不可估」；统计状态未完整时显示「本次部分预估」。运行期间不显示最终费用，中断或失败不追加正常完成的费用标记。原有结束时间缺失时仍不伪造时间或完成记录。

## 并行数量

设备以其当前实时快照中的运行会话计数；项目以目录中全部非归档成员计数，在搜索过滤前汇总。离线设备、断开的运行时及其他设备的缓存不显示运行标记。只有一个运行会话时显示橙色动画点，两个及以上在点旁显示数字；结束后立即减少数量，全部结束则隐藏。数量不包含尚未开始的排队消息。

项目收起时显示项目标记和数量，展开后保留各运行会话的点，隐藏项目点和数字。设备标记继续显示。数量受当前配置的实时同步范围约束；尚未同步进实时快照的活动会话无法计入。

## 更新范围

Web 用户更新服务器与 PC Agent 后生效。旧 Agent 缺少统计字段时，控制端显示待同步；旧客户端仍可读取普通目录。Android、Windows/macOS Control 需要包含这次共享界面的新原生安装包；源码和 Web 验证不代表这些原生包已构建或手机已实测。
