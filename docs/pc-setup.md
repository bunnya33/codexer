# Codexer Agent：安装与使用

## 普通用户安装

Windows x64 新版使用 `Codexer-Agent-Qt-Setup-<版本>-x64.exe`（安装版）或 `Codexer-Agent-Qt-Portable-<版本>-x64.exe`（便携版），位于 `apps/agent-qt/release`。2026-10-30 起优先将连接器迁为 Qt；Mac 暂保留既有 Electron DMG/x64 包，Qt Mac 源码需独立编译验收。与原生控制端 Codexer Control 使用不同图标。无需安装 Qt、Node、npm、Git 或下载源码。构建决策见 [桌面架构](desktop-native.md)，签名流程见 [发布](release.md)。

本机必须已安装并登录官方 Codex，任务使用该电脑原有的模型、账号/密钥、工作目录和权限。连接器不代替官方 Codex。macOS 安装和验证见 [macOS 文档](mac.md)。

Qt Agent 使用原生本地管理界面及系统标题栏，支持拖动、最小化、最大化/还原和关闭。默认关闭缩小到托盘；取消设置中的“关闭窗口时保留在托盘”后，每次关闭均需确认。托盘提供重启、运行时刷新和释放空闲会话。

## 首次连接

1. 启动 Codexer Agent，进入“连接状态”。
2. 填写管理员给出的服务器根地址，例如 `https://relay.example.com`。地址不能附带路径、用户名密码、查询或 fragment。
3. 设置设备名称，输入普通账号及密码，点击“登录并连接”。
4. 等待 Relay 和本机 Codex 运行环境可用。在手机或服务器首页用同一账号登录后选择这台 PC。

用户名密码与官方 Codex 登录不同。设备按本地 installationId 自动归属账号，无需令牌、配对码或后台分配。同账号、同安装重新登录保持设备标识；账号改密、禁用或会话到期后需要重新登录。

默认只允许 HTTPS 和本机 HTTP。内网测试可在设置中打开“允许远程 HTTP”；HTTP 明文传输账号与任务，不适合公网。

## 按钮与状态

| 操作 | 结果 |
| --- | --- |
| 登录并连接 | 验证账号，系统加密保存会话，启动本机服务，连接 Relay |
| 连接 | 使用已保存的有效会话连接；不需重新输入密码 |
| 断开 | 暂停重连和新远程指令，暂停待发送消息；已运行任务继续 |
| 重连 | 主动重建远程 socket；保持本机服务、任务与 epoch |
| 退出登录 | 先断开，清除本机会话，请求 Relay 撤销；已运行任务继续 |
| 关闭窗口 | 默认留在托盘，不停止连接与任务 |
| 托盘“退出” | 停止连接器；有活动任务时提示 App Server 将停止 |

网络故障会指数退避重连，最长约 30 秒。手动断开不会因网络恢复自动连接；“启动后自动连接”只在下次启动且会话有效时生效。401、会话撤销或连接被替换会停止重试并要求重新登录。

协议/策略拒绝（如 `1008`）会显示脱敏原因并暂停自动重连，保留账号会话和本机任务。修复或更新后点击“重连”，无需因为协议错误重新登录。服务器保存状态失败（`1011 storage-error`）会指数退避重试；短暂握手成功不会重置退避。

## 设置

- **服务器与设备名称**：修改后需要重新登录，重新连接采用新配置。
- **Codex 数据目录**：默认当前用户的 `.codex`，可选择其他官方 Codex 配置目录。
- **Codex 程序路径**：默认自动查找；Windows 优先官方安装的最新 `codex.exe`，也检查 PATH。找不到时选择可执行文件。
- **运行方式**：自动优先桌面 IPC，桌面不可用时尝试本机 App Server；也可只用桌面或 App Server。
- **开机启动**：登录操作系统后启动连接器。便携版需要保持可执行文件路径固定。
- **自动连接**：启动时恢复有效账号会话并连接，密码不会保存。
- **关闭窗口时退出进程**：默认关闭，关窗口进入托盘；启用后关窗口确认退出。

运行配置修改前会检查本机任务，有任务或状态尚未确认时阻止修改/重新登录，避免关闭运行服务。启动偏好可以独立调整；运行配置保存后需主动连接。

## 远程新建项目

服务器 `0.3.5` 与 PC 连接器 `0.1.11` 支持新建项目。先在电脑端「设置 → 新建项目的目录权限」添加允许的父目录，保存后点击连接。默认没有授权；更改或移除授权也需要保存、重新连接，有活动任务时暂不能更改。

手机或网页打开项目列表，选择这台电脑，点击「新建项目」，选择已授权的父目录，填写项目名称与相对文件夹路径。可以新建最后一级文件夹，或添加已有文件夹；例如 `apps/demo` 要求 `apps` 已存在。项目注册成功后会立即出现在列表中，展开后点击新建会话按钮即可使用。添加已经注册的文件夹会复用该项目，不重命名或删除原有文件。

授权覆盖父目录的普通子目录。Agent 在本机检查路径，拒绝绝对路径、`..`、特殊文件名与符号链接。Relay 不接受远程新增目录授权；失效或被替换的授权目录会拒绝操作。仅桌面 IPC 模式不能创建项目，请使用自动或 App Server。当前在本机 Codex CLI `0.159.2` 验证了项目注册和会话创建；这依赖实验性项目接口，旧 Codex 版本可能需要更新。

目录授权只约束此功能，不是 Codex 后续命令的系统沙箱。新会话明确采用 `workspace-write` 和 `on-request`，既有会话保留原来的执行权限和审批。工作区外的读写范围仍由 Codex 的沙箱、配置与审批决定。

命令行 Agent 可以重复指定 `--project-parent /absolute/path`；不指定时默认拒绝创建。注册结果不确定时先刷新项目列表；如果文件夹已经创建但项目没有出现，使用「添加已有文件夹」继续，不自动清理用户文件。

## 凭据与诊断

Codexer Agent（Windows/macOS 共用 Electron `0.2.10`）上报自身安装包版本，控制端 `0.3.25` 的「设置 → 版本信息」可查看当前设备版本。旧 Agent 显示「未上报」，须在电脑端设置中核对；发布服务器包不会自动替换电脑端安装包。

会话在 `.jsonl` 和 `.jsonl.zst` 之间切换时，现在重新定位文件并有限重试；接口仍返回压缩路径、但会话已恢复成普通文件时，优先读取当前普通文件。读取过程中尺寸/修改时间改变会重新读取，最多三次；不跳过损坏行，不从损坏的当前文件回退到旧压缩权限，也不以默认权限继续发送。仍然失败时区分文件缺失、访问被拒绝、文件占用/变化、内容损坏等诊断代码，控制端显示中文说明并保留代码，Agent 本机诊断日志也记录这些脱敏代码。旧版 `headless-settings-unreadable` 仍可提示检查版本、数据目录与本机诊断。此变更已做合成回归，未取得报错 Mac 的实际文件或版本，不能据此断定该设备的具体原因；稳定缺失、损坏或系统拒绝访问需在该电脑处理。

新版 Codex 可能将较旧的会话保存为 `.jsonl.zst`，但接口仍返回原来的 `.jsonl` 路径。PC 连接器 `0.1.14` 支持直接读取这些压缩会话；旧版远程发送时可能出现 `headless-settings-unreadable`，请更新该电脑的连接器，服务器无需更新。恢复会话仍检查原有沙箱、审批和工作目录权限；文件损坏或权限不完整时拒绝发送。桌面安装包自带所需运行环境；从源码运行命令行 Agent 并读取压缩会话时需要 Node >=22.15。

凭据使用 Electron safeStorage 系统安全存储，保留旧加密身份；原生 Agent 凭据成功迁移后转存为 Electron 格式。只保存会话，不保存密码；安全存储不可用时拒绝持久登录。账号会话不传入界面。

“诊断日志”展示安全存储、登录、Relay、本机 Codex 的检查结果；导出仅含版本、平台、连接状态和诊断代码。不会导出服务器地址、账号、密码、会话、任务内容或本地目录。磁盘日志超过约 1 MiB 轮换一份。

Windows 本地数据优先位于 `%APPDATA%\Codexer`，兼容现有 Windows 安装版；macOS 沿用 `~/Library/Application Support/@codexer/desktop`。`settings.json` 保存地址、账号名等设置，`session.enc` 保存系统加密会话；历史 `session.native.enc` 在成功迁移后删除，`agent/<deviceId>` 保存本机命令/用量数据库。卸载前先退出登录；诊断或导出时不分享整个应用数据目录。

“已连接”只说明远程通道可用；本机运行环境若仍在等待，查看诊断、确认官方 Codex 已登录、程序和数据路径正确。完整排查见 [运维](operations.md)。源码开发入口见 [开发文档](development.md)。
