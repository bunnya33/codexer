# 会话界面、提问与 Plan Mode

## 会话权限和网站／应用授权

服务器 `0.3.17` 和 PC 连接器 `0.1.15` 增加权限入口：在输入区的权限按钮中选择只读、请求批准、帮我批准、完全访问。只允许在电脑在线且会话空闲时修改，界面展示官方确认后的设置；与标准预设不一致的配置显示为自定义。选择完全访问需要另点确认；管理配置不允许的选项会返回错误，不会假装成功。

Browser 网站访问和 Computer Use 应用访问请求会出现在当前会话中，显示网站来源或应用名称。可允许一次、拒绝，或使用官方请求明确提供的本次会话／始终允许选项。桌面 IPC 和独立 Agent 都使用官方回复接口，已完成、过期或轮次不符的请求拒绝再次提交。当前不提供“允许所有网站”，也不代理登录表单、未知授权或系统权限弹窗。macOS 的屏幕录制、辅助功能和钥匙串授权仍需在本机确认。原生手机 App 需重新构建才包含新界面；网页版随服务器更新。

## 控制端皮肤

在「设置 → 外观 · 皮肤」中选择默认、暖白纸张或暖棕暗色。点击立即应用，偏好保存在当前设备／浏览器，重新打开后恢复；不会切换会话或清除未发送草稿。皮肤统一覆盖侧栏、消息、输入框、设置、提示、文件阅读、代码块和代码差异；新增保持绿色、删除保持红色。新皮肤的浮层菜单使用柔和半透明背景，支持的平台提供模糊效果；正文保持实色。

网页随服务器 `0.3.15` 更新；Windows 原生控制端和原生手机 App 的界面随客户端交付，需要对应的新客户端，刷新网页不会升级原生客户端。此功能不改变 Agent、接口或数据库。


适用于 React Native 控制端及 Web 导出，PC 使用更新后的 Agent/连接器。基本操作见 [控制功能](usage.md)，安装见 [服务器安装](server-install.md) 和 [PC 连接器](pc-setup.md)。

## 滚动和活动状态

手机 App 与窄屏 Web 使用跟手侧栏：在会话正文横向右拖时，会话卡片随手指向右移动，露出下面的项目/会话列表；有效滑动后，即使停顿再松手也会平滑展开，向左滑则收回。短距离误触保持原来的开关状态，快速划动按方向完成过渡；取消或多指手势返回原状态。展开后点击露出的会话区域或关闭按钮可返回；菜单按钮使用同一动画。Web 支持 Escape，Android 支持返回键。宽屏 Web 保持固定侧栏及细分隔线，不使用手机抽屉阴影。列表与会话始终保留实例，不清空草稿或滚动位置；上下阅读、代码/表格的横向滚动、输入和图片预览不参与侧栏手势。“减少动态效果”关闭松手后的过渡。

进入或切换会话默认到最下端，包括已缓存的会话。停在底部时保留跟随状态，新卡片插入后立即滚到真实末尾，后续高度更新继续贴底；消息行数、输入框收缩、列表重新测量和迟到的位置回调均不会自行暂停跟随。只有主动向上滚轮、滑动、按键或拖动滚动条才暂停，即使只挪动几像素也保留阅读位置；暂停后消息、预览或编辑框高度变化不会重新开启跟随。离开底部超过约 100px 后在编辑框上方显示圆形下箭头。点击后立即到底部并恢复跟随；手动向下滚回底部 24px 容差范围也恢复跟随。距离阈值只用于手动返回底部和按钮显示，不用于新内容插入后的跟随决策。Web 在底部继续向下滚轮、按键或滑动不会误暂停跟随，输入框、内部可滚动区域、横向滚动和缩放手势不影响外层会话跟随。

有更早记录时，向上滚动到距顶部约 64px 内自动加载上一页；Web 已停在顶部时再次向上滚轮、按键或滑动也能触发，无需点击按钮。加载期间拦截重复请求，加载后补偿阅读位置；失败后再次上滑或点击“加载更早消息”可重试，历史读完后停止请求。顶部按钮仍保留，手机 App 同时保留下拉加载。

连续的思考、命令和文件操作默认合为一组，只展示最新活动。展开的记录向右缩进并带浅色层级线，摘要保留原位置；箭头旋转和高度展开动画保持。执行时展示当前公开的思考摘要或命令/文件操作；结束后按实际活动汇总，例如“已创建 helper.ts，编辑文件并运行命令”。记录行显示具体命令或文件名，长文字只占一行，点击可查看详情。

执行中的摘要使用较浅的文字和扫光，完成后停止；系统开启“减少动态效果”时关闭扫光。仅使用 Codex 提供的公开 summary 和已观测工具操作，不读取隐藏思考内容；没有公开摘要时保留“正在思考/已思考”提示。准确的创建/编辑/删除类型需要 PC 连接器 `0.1.5` 或以后版本，以及更新后的 Relay；旧 Agent 的文件记录按“修改”显示。

通用“部分内容已截断”不再重复占据回复底部。有展示限制时，标题栏「会话选项 → 会话展示范围」说明范围；具体差异被截断时，展开后仍提示。传输的条目数量、文本和差异大小限制仍保留，完整原始内容在本机 Codex 查看。

## 紧凑标题栏与子 Agent

会话顶部保留一行工具栏：标题、项目/运行提示、子 Agent 按钮和「…」会话选项。原来独占一行的微信通知开关移入会话选项，刷新及展示范围说明也放在这里。微信通知已开启（包括总开关开启）时，「…」旁显示绿点，设置仍跟随账号同步。

机器人按钮显示子 Agent 数量；运行时显示「运行及等待数/总数」，例如 `2/3`。点击打开详情弹窗，查看名称、任务、状态；点击单项展开角色、模型和最近消息。手机、Web 和 RelayDesk 使用相同的界面。切换会话会关闭弹窗，关闭不会中断任务。

PC Agent 从官方 `collabAgentToolCall.agentsStates` 和 `subAgentActivity` 获取最近已知状态，桌面模式还使用 Codex 更新的 `receiverThreads` 会话状态。先汇总 Agent，再裁剪消息，避免较早的创建记录被长命令输出挤掉。独立 App Server 模式通过只读的后代会话查询校准状态，子会话事件和轮询触发更新，不启动或恢复子任务。运行、等待、空闲、完成、中断、出错、关闭与未知状态分别显示；工具调用完成不代表子 Agent 完成。

PC 连接器 `0.1.10` 还会读取本机子 Agent 的会话记录，补充昵称、模型、可读取的任务说明、最近公开回复及完成/中断事件。只读取当前主会话引用的子 Agent，并核对记录中的子会话 ID 和父会话 ID；文件必须位于配置的 Codex 会话目录。每 3 秒检查一次，新增文件索引最长 15 秒刷新，未变更的文件不重复读取，变更时每个文件最多读取开头和末尾各 256 KiB，不等待主会话出现新消息。子 Agent 正文或状态改变也会同步到控制端，服务器不保存完整子会话文件。

状态来源区分「会话状态」和「最近活动记录」；断线后标注最后同步记录，不能视为实时状态。部分新版 Codex 子任务只记录加密正文，没有可读取的任务说明；界面明确提示记录未提供正文，不把它显示为等待同步。只同步可读取的公开消息，不解析加密块、开发者指令或隐藏推理，不显示虚构的完成百分比。最多同步 32 个 Agent，优先保留运行任务，长内容和更多历史记录受大小限制并标注。旧 PC 连接器显示更新提示。

此功能需要同时更新服务器 Web/协议和 PC 连接器 `0.1.9`（源码 Agent 需重新构建并重启）。RelayDesk 加载服务器控制页面，这次业务界面无需更换桌面壳。官方接口有实验性质；已核对本地 Codex `26.930.7945.0` 桌面 bundle 的状态转换。

## 刷新与历史顺序

实时状态与历史分页按同一条消息的服务器身份合并。Codex 桌面中的追加消息有独立的临时 ID；Agent 使用其 `serverUserMessageId` 或明确关联的客户端消息 ID 对应已保存的用户消息，隐藏内部 `steered` 占位条目，避免刷新后重复和错位。不按文字去重，用户主动发送两条相同内容仍保留两条。重叠分页和实时轮次按相邻已知轮次插入，避免较早的轮次被追加到最后。

该修复需要更新服务器 Web 和 PC 连接器（Windows `0.1.6` 或以后版本）；源码 Agent 需重新构建并重启。旧连接器没有同步正确的消息身份，只刷新网页不能完整修复。

## 图片查看

点击会话图片后，按当前已加载会话的消息顺序浏览图片；左滑下一张，右滑上一张。查看器显示页码和上一张/下一张按钮，Web 也可用键盘左右箭头。首尾不循环，只有一张时隐藏翻页按钮。

原始大小时滑动翻页，放大后拖动查看图片细节，不触发翻页；双指缩放保持原有行为。切换图片恢复原始大小。图片仍通过账号认证获取，凭据不进入图片地址。加载更早记录后重新打开查看器，可浏览新增的历史图片。

## 文件修改面板

执行中的当前轮次产生修改后，在编辑框外部、上方固定显示胶囊：`2 个文件已更改 +32 -4`。新增绿色、删除红色，位置不随会话滚动。点击展开可滚动的差异区域，再点击收起。

执行结束、停止或失败后，胶囊消失，该轮次恢复原来的“已编辑 N 个文件”面板，放在对应回复下方。之前完成的轮次也使用原来的面板。统计来自已观测的成功文件编辑事件，不是扫描整个仓库，也不把分页历史的多轮修改重复累计。

两种面板展开后均先显示文件路径及各自的新增/删除数量，点击文件名才显示其差异。每个面板同时只展开一个文件，切换文件自动收起上一个；再次点击文件名收起，关闭总面板后再次打开恢复文件列表。差异新增行使用绿色文字/浅绿背景，删除行使用红色文字/浅红背景；文件头保持灰色，区块标记单独区分。长行可横向滚动，大段差异限制可视高度并允许滚动，代码按纯文本显示。差异不可用和截断说明仅在对应文件展开时显示。

## 文件链接和微信通知

回复中的本地文件链接可点击，支持中文、空格、Windows 和 Unix 绝对路径。MD 在 Markdown 阅读器显示，TXT 及其它常见文本可选择复制，JSON 自动格式化并可复制；阅读器提供下载和关闭按钮。文件从 PC 按需获取，服务器只中转、不保存内容。PC 离线、文件移动/删除或版本变化时显示错误，可重试重新读取。

PNG、JPEG、WebP、GIF、BMP、ICO、AVIF 和 SVG 文件链接点击后直接弹窗预览，可缩放查看并按需下载，不先询问是否下载。图片不受 2 MiB 文本预览限制；损坏图片或当前平台不支持的格式会显示提示，仍可下载。关闭预览会取消未完成读取，并释放浏览器内存中的图片。

EXE、压缩包及其它不支持预览的格式先显示文件名、大小和「是否下载此文件」，取消后不请求内容。超过 2 MiB 的文本也需下载后查看，文件传输上限 512 MiB。网页使用浏览器下载；App 获取后交给系统保存/分享。关闭阅读器或切换会话取消未完成请求。

会话顶部「会话选项 → 本会话微信通知」默认关闭；总设置「任务完成通知」开启时通知全部已监听会话，关闭时只通知单独开启的会话。偏好跟随账号，其它登录设备同步。总开关开启时界面会提示全部会话都会通知，此时会话开关只记录供总开关关闭后使用的偏好。

## 回答问题

本机发出有效提问时，控制端显示“回答问题”卡片。兼容两种官方格式：`item/tool/requestUserInput` RPC 请求，以及桌面异步 `agentMessage.questions`（每项包含 `title` 和可为空的 `options`）。后者不在待处理 RPC 列表中，Agent 从当前轮次的消息识别并同步为可操作请求。

支持选项和描述；点击预设选项立即发送，不需要再点击提交。只有选择自定义回答或无选项的文字题显示提交按钮。消息提问按题发送，回答后保留其余未回答问题；RPC 多题需要完整答案，全部选好预设选项后自动发送，包含文字题时填写后手动提交。RPC 允许 `isOther` 时可输入自定义回答，消息提问始终支持自定义回答。`isSecret` 输入使用密码形式，不保存到浏览器草稿存储。

答案使用原始问题 ID，经 Relay 和 Agent 回传官方接口。RPC 使用原生回答接口；消息提问使用官方的结构化回答包装，通过桌面 `thread-follower-steer-turn` 或独立 Agent 的 `turn/steer` 引导当前轮次。提交期间防止重复点击；失败保留输入以便重试，成功等待本机更新。离线、owner 不可用、问题已解决或格式不支持时不能回答。没有结构化问题数据的纯文字不会自动变成可操作请求。

消息提问只在来源轮次仍执行时有效；完成、停止或收到已接受的回答后，卡片移除。待接受/已拒绝的引导消息不算回答。RPC 的同步提问绑定当前轮次；RPC `isBlocking:false` 请求只要仍有效，允许原始轮次结束后回答。这两种异步格式的有效期不同。

历史中的 `send_user_message_question_reply` 包装会显示为正常的问题和回答：气泡内问题使用浅灰色，答案使用正常深色。Agent 同步结构化展示字段以保留两者关系，隐藏内部标签、JSON 和问题标识，保留包装之外附加的文字。长回答先解码再应用展示长度限制。正在显示可操作卡片时，消息里的重复提问文字隐藏；处理后保留会话历史。

Codex 桌面程序的自动结束计时由其本机服务管理，当前 follower IPC 不同步准确截止时间或延后操作。弃用的 `autoResolutionMs` 是时长，不能代表剩余秒数。因此控制端不模拟倒计时、不预选默认答案、不额外自动提交。非阻塞请求提示“任务可继续执行”，有效期以实时状态为准。

此修复需要同时更新服务器的 Web 资源及 PC 连接器（Windows `0.1.4` 或以后版本）；只刷新旧网页或只替换服务器，不能让旧 Agent 支持按题回答及问题/答案颜色区分。使用源码 Agent 时重新构建并重启。

## 设置弹窗

服务器 `0.3.18` 在网页预览卡片和展开预览的工具栏中增加「分享网页」。打开弹窗只查询已有链接，点击「创建分享链接」才开启公开访问；之后可以复制、停用、重新开启或重新生成。重新生成需确认，旧链接和已建立的连接立即失效。同一电脑、端口和页面路径复用固定链接，持有链接的人无需登录；关闭控制端或退出登录后仍可访问。

分享实时转发电脑上的网页，不上传为静态托管页面。电脑需在线，网页服务需运行；暂停服务后链接暂不可用，恢复后重新打开原链接即可。端口分享包含这个网页服务的资源和接口。HTML 文件分享读取当前源文件，限 2 MiB 的 UTF-8 HTML/HTM，不包含相邻文件；有资源目录或接口的页面应通过本地网页服务分享。源会话需仍在设备目录中，Agent 需保留来源授权。服务器/Web 控制端需更新，现有支持网页/文件预览的 Agent 可继续使用；原生控制端与手机 App 需独立构建更新。

模型与推理强度合并为工具栏中的一个按钮，显示当前模型和强度。点击后在按钮上方向上展开圆角浮层：蓝色文字显示当前强度，下方模型名称可切换到模型列表，底部使用分档滑块；松手或完成键盘调节后才保存，失败恢复已保存值。工作模式、设置、微信设置和会话管理均为居中淡入弹窗，保留现有手机侧栏。

排队消息连接在输入框上方，每行直接提供「引导、删除、编辑」，不经过更多菜单。编辑弹窗读取完整正文，保存时保留图片和文件附件；消息已发送/移除或在其它客户端修改时显示错误，保留编辑草稿。此功能需要同时更新服务器及 PC Agent 源码。未发送图片的缩略图可点击进入现有图片查看器，支持缩放和多图切换。

「＋」打开按钮旁的相机、照片和文件菜单。通用文件先分块上传，再由 PC 连接器校验并保存到本机私有附件目录，以本地文件引用发送给 Codex；不把任意文件伪装成图片。文件能否解析取决于 Codex 的现有工具和权限。每条最多 4 个文件、单个最多 20 MiB；仅发送文件也有效。排队前已保存本机副本，服务器清理暂存文件后仍可继续发送队列。

## Plan Mode

更新后的 Agent 广播 `runtime.capabilities.collaborationModeUpdate`，工具栏出现工作模式按钮。会话空闲、模型已同步、设备及 owner 在线时，可选默认模式或 Plan Mode；运行中禁用切换。旧 Agent 不显示入口。

切换使用真实 `collaborationMode`，保留模型、推理强度、工作目录和权限策略，使用官方内置模式指令。Plan Mode 用于讨论和形成计划；准备执行时切回默认模式再发送执行请求，不会自动切回执行。

桌面 owner 使用 `thread-follower-update-thread-settings`，独立 Agent 使用 `thread/settings/update`，后续 `turn/start` 携带模式。命令携带预期模型、强度和模式。桌面 IPC 的条件字段只提供模型/强度检查，模式另在本机当前快照检查；与本机同时操作时以最新状态为准。
