# 删除空项目

项目行右侧的 `…` 菜单提供「新建会话」和「删除项目」，项目收起时也可打开。只有会话数为 0 的项目才能删除，归档会话也计入；搜索过滤不会改变判断。「未归类会话」是分组，没有项目删除入口。电脑离线时不可执行删除，旧 Agent 会显示更新提示。

点击「删除项目」后，电脑端重新核验项目及会话，弹窗显示项目名称和实际目录，可选择：

- 「删除项目，保留目录」：只移除 Codex 项目登记，保留所有本地文件。
- 「连同目录一起删除…」：进入第二次确认，显示所有目录及不可恢复提醒，点击「永久删除项目和目录」才提交。

第二次确认可返回上一步，弹窗也可取消。确认信息 5 分钟有效，期间项目属性或目录身份变化会要求重新确认；新增会话会阻止删除。

Agent 使用官方 `project/list`、`thread/list`、`project/delete`，枚举普通/归档会话、所有来源以及状态数据库/会话文件中的记录，不能完整核验时拒绝删除。未发送消息的本机新会话也会阻止删除。Relay 按设备所属账号鉴权，命令沿用 epoch、有效期和幂等日志。

目录只取自电脑端重新读取的项目登记，客户端不能传入任意路径。Agent 核验目录及其父级身份，拦截文件系统根目录、用户主目录、系统/运行环境及 Codexer 数据目录、目录链接、挂载点、重叠或共享项目目录，以及其他会话正在使用的目录。受保护目录仍可选择仅移除项目登记。支持多个互不重叠的项目根目录，确认弹窗列出全部路径。

删除前再次检查项目为空及目录身份，官方项目登记删除后还会检查目录是否被其他项目或会话使用，再删除文件。官方 API 不提供跨进程的项目/文件系统事务，因此并发的本机操作不能与远程删除形成原子操作。文件删除遇到权限、占用、检查失败或部分失败时，会明确提示「项目已删除，但目录未能全部删除」；不自动重试文件删除。剩余文件保留在原目录或同级 `.codexer-delete-<唯一标识>` 目录，弹窗列出当前剩余路径，需在电脑上检查。

需同时更新 Relay 和 Agent；Web 随服务器更新，Android/Windows/macOS 原生 Control 需更新相应客户端。此功能源码完成不代表已发布更新包或已安装到生产服务器。
