# 管理后台

管理后台是一套独立 React + Vite 应用，代码在 `apps/admin`，生产地址为服务器根地址的 `/admin/`。与 Relay 和 Web 控制端一起安装，无需单独启动后台服务器或开放端口。

## 登录和账号管理

使用安装时生成的管理员账号密码登录。后台仅接受管理员，普通用户尝试登录会撤销该次会话。管理员账号自身也不拥有跨账号 PC 访问权限。

| 功能 | 使用与结果 |
| --- | --- |
| 查看账号 | 显示名称、角色、启用/禁用状态，定期刷新 |
| 创建账号 | 输入用户名和 12–128 字符密码，创建普通账号 |
| 重置密码 | 为现有普通账号设置新密码，撤销该账号所有既有会话 |
| 禁用账号 | 阻止继续登录、撤销会话及连接；历史数据保留 |
| 登录超时 | 设置控制端与后台离开前台后的有效时长，按最后前台时间计算 |
| 退出登录 | 注销当前后台会话并清除保存的登录状态 |

用户名忽略大小写且唯一。禁用不是删除数据，目前没有重新启用入口；需要新账号时使用其他名称。管理员不能通过此入口禁用自身。客户端和 PC 登录同一普通账号后自动关联，无需管理后台分配设备。

## 登录超时设置

账号列表下方的“登录超时”可输入分钟、小时或天，范围 1 分钟至 30 天，默认 7 天。例如设为 24 小时：离开网页/App 后在 24 小时内回来继续使用，超过后重新登录。页面/App 在前台时自动续期；后台设备数据和 WebSocket 心跳不会延长登录。

保存后对现有控制端和后台登录生效，按各次登录最后在前台的时间重新计算；缩短时长可能使较久未使用的登录立即过期，延长不会恢复已经过期的登录。设置保存在 Relay 数据库，重启、升级时保留。PC Agent 会话保持原有 7 天有效期。退出、改密、禁用的立即失效规则不受此设置影响。

前台每 30 秒续期，离开页面/App 时还会尝试记录最后在线时间。系统强制终止页面或网络不可用时，超时从服务器最后成功收到的续期开始计算。

## 与控制端隔离

`/` 是 React Native Web 控制端，`/admin/` 是 React 账号管理后台，资源独立构建。后台不读取设备、项目、会话，也不建立控制 WebSocket。

后台 localStorage 使用 `codexer.admin.session.v2`；控制端使用自己的 key。刷新或关闭后重新打开页面可恢复未过期的登录，并自动迁移旧 sessionStorage 登录；退出或会话过期清除。短暂网络故障重试恢复，只有服务端确认会话失效才清除。浏览器存储不可用时允许内存会话；不会保存密码。使用 HTTPS，共享电脑用完后退出登录。用户主动清理站点数据或隐私浏览退出仍会丢失浏览器保存的登录。

## 故障与开发

忘记管理员密码：systemd 安装执行 `sudo codexer password`；Docker/开发环境参考 [运维恢复](operations.md)。页面空白或 `/admin/` 返回 404，确认 `RELAY_ADMIN_DIR` 指向已生成的 `apps/admin/dist`，不要把它指到 Expo Web 产物。

开发运行 `npm run dev:admin`，默认 `http://127.0.0.1:5174/admin/`，Vite 将 `/v1` 代理到本机 Relay 8787。可设置 `CODEXER_RELAY_URL` 调整代理目标。构建 `npm run build:admin`；类型检查 `npm run typecheck --workspace @codexer/admin`。接口见 [API](api.md)。
