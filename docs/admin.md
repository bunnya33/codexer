# 管理后台

React + Vite 管理控制台随 Relay 和 Web 一起部署，访问同一服务器的 `/admin/`。侧栏含仪表盘、控制端账号、后台管理员和系统设置；顶部显示当前管理员，手机宽度使用抽屉导航。

## 两类账号

| 类型 | 登录位置 | 权限 |
| --- | --- | --- |
| 后台管理员 | `/admin/`，`/v1/admin/auth/login` | 管理账号、登录策略、查看服务状态、服务器更新 |
| 控制端账号 | Web `/`、App、PC Agent | 查看和控制同账号登录的 PC |

两类账号独立，同名账号允许使用不同密码，不能互相登录。后台不读取任务内容，也不能申请控制端的 WebSocket 票据。首次管理员沿用安装器生成的账号密码；已有管理员不会在重启时被环境变量覆盖。

旧版若曾使用管理员账号连接 PC，升级后该账号不能继续用于 Agent。创建一个控制端账号，再在 PC 连接器和 Web/App 登录它；旧设备与内容仍保留，不自动转移到新账号。

## 页面与操作

- 仪表盘显示真实账号数量/启用量、在线 PC、在线控制连接和进程运行时长。连接数不是用户数。
- 控制端账号：创建、搜索、重置密码、禁用。密码为 12–128 字符；改密/禁用立即撤销当前登录和 PC 会话，现有数据保留。
- 后台管理员：独立列表、创建、改密和禁用；服务器拒绝禁用当前管理员或最后一位有效管理员。重置自己的密码后需重新登录。
- 系统设置：离线登录超时 1 分钟至 30 天，默认 7 天，保存对已有控制端/后台登录立即生效。PC Agent 的固定有效期不受此项影响。

管理后台和控制端使用不同的 localStorage session key。离开页面时记录活动时间，在前台每 30 秒续期；网络错误保留登录，只有认证失效才清除。退出撤销当前登录。

后台修改管理员密码后，`relay.env` 中的首次密码不会自动同步；CLI 账号操作在旧密码失效时会提示输入当前管理员密码。执行 `sudo codexer password` 可同时同步数据库和受限配置。不要删除数据库恢复账号。

## 左上角版本入口

当前版本徽标：确认无更新时绿色圆点，有新稳定版本时橙色呼吸圆点；无法检查或暂无可安装 Release 时灰色，避免误报“最新”。点击打开版本弹窗，支持重新检查、查看发布日志和立即更新。

Linux systemd 安装器管理的服务支持一键更新以及默认关闭的无人值守更新。其他部署仍可检查版本；Docker/源码部署使用外部更新流程。具体流程、校验和回退见 [服务器更新](server-update.md)。

## 开发

`npm run dev:relay` 加 `npm run dev:admin`；后台开发地址 `http://127.0.0.1:5174/admin/`，Vite 默认代理到本机 Relay 8787，可通过 `CODEXER_RELAY_URL` 调整。生产构建 `npm run build:admin`，类型检查 `npm run typecheck --workspace @codexer/admin`。接口见 [API](api.md)。
