# Codexer 控制端交互改造：完整功能确认稿

日期：2026-11-08。状态：范围已确认，功能细则待整体评审；正式应用改造尚未开始。

本稿承接 [交互与样式方案](mobile-interaction-redesign-plan.zh-CN.md)，用于先确定完整功能，再进行正式开发。参考为用户提供的 24 张截图、6 段录屏；源码核对基线为 `main / 6560b1a`。参考媒体中的文字和操作示例只作为设计素材。

## 1. 已确认的范围与本稿使用方式

| 项目 | 确认结果 |
| --- | --- |

| 项目搜索 | 同时支持文件名、相对路径和文件内容搜索 |
| 计划执行入口 | 先将执行指令放入输入框，用户可补充，主动发送后才执行 |

| 当前工作顺序 | 完成功能确认和其余页面的交互核对，再接入正式应用；当前继续完善网页预览，不先制作安卓演示包 |
| 跨端关系 | Web 与手机共用功能语义、状态和视觉体系；键盘、返回、文件选择和系统分享按平台适配；宽屏保留有效的信息密度 |
| 技术约定 | Control 继续 React Native 原生宿主；新增远端能力由 Qt Agent 同进程 C++/Qt 后台提供 |

“已确认”指上表及此前用户明确要求的行为；后文补充的默认细则属于本次评审提案，并不代表用户逐条批准。技术实现选择可在这些规则内调整，不能据此改变已经确认的功能。

本轮不纳入快速模式、插件管理、目标管理、置顶、语音通话、文件编辑或 Git 写操作。跨 PC 已读同步尚无可靠依据，蓝色未读点继续暂缓。现有连接、通知、更新和微信 ClawBot 功能保留。

## 2. 页面与入口清单

| 页面/区域 | 入口 | 提供的操作 | 返回结果 |
| --- | --- | --- | --- |
| 设备、项目、会话侧栏 | 顶部左侧按钮；符合条件的侧滑 | 切设备、展开项目、搜索会话、创建和现有管理操作 | 返回目标会话；原会话草稿保留 |
| 主会话 | 选择会话 | 阅读、展开处理记录、发送/引导、停止/继续、设置、回答、审批 | 会话持续同步 |
| 会话标题菜单 | 标题栏 `…` | 现有重命名、复制 ID、归档、删除、刷新及显示/通知相关操作 | 关闭菜单后保持阅读位置 |
| 输入附件菜单 | 输入区 `＋` | 相机、照片、视频、文件、方案模式入口 | 保留输入焦点或回到输入区 |
| 快捷模型控件 | 仪表入口 | 查看模型和强度、拖动强度、进入高级设置 | 回到输入区，显示真实设置 |
| 权限面板 | 加号后的权限图标 | 查看真实权限、选择预设、完全访问确认 | 入口图标同步成功保存的值 |
| 问答/审批卡片 | 会话中的待处理请求 | 翻页、选择、自定义回答；允许/拒绝等真实决策 | 显示已提交/等待同步或失败 |
| 完整计划阅读器 | 计划卡片 | 完整阅读、复制、下载/系统分享、准备执行 | 回到原卡片；不自动发送 |
| 文件面板 | 更改胶囊、文件摘要、项目菜单中的“浏览文件” | 已修改/所有文件、目录树、搜索 | 返回原会话或项目位置 |
| 差异/源码阅读器 | 文件列表、搜索结果或会话内文件链接 | 差异、源码、行号、复制、下载、支持的预览 | 恢复目录、搜索及各自阅读位置 |
| 设置 | 侧栏设置入口 | 常规、外观、服务器与设备、更新与下载、关于；保留现有其他入口 | 返回原会话 |

无当前会话也可从项目菜单浏览该项目；页面明确显示当前设备和项目。菜单和系统返回不会停止正在运行的任务。

## 3. 所有功能共用的状态规则

连接状态、任务状态、操作待确认状态分别表达。例如“任务仍在运行，但设备刚离线”应同时展示，不能把断线误判为任务结束。

| 状态 | 展示与可用动作 | 退出状态的依据 |
| --- | --- | --- |
| 首次同步/切换接入 | 加载提示，可阅读已缓存内容、编辑本地草稿；远端写操作等待就绪 | 新设备/会话快照就绪 |
| 空闲 | 正常阅读和编辑；有内容才可发送 | 实际开始新轮次 |
| 运行中 | 橙色状态、实时记录；有内容发送引导，空输入停止 | 真实完成、中断或错误事件 |
| 等待回答/批准 | 具体待处理提示和卡片；仍属于尚未结束的活动轮次 | 请求被回应、撤回或失效 |
| 停止请求中 | 显示“正在停止”，避免重复点击；不能提前展示继续 | 中断确认/快照，或停止失败 |
| 已中止 | 清楚标注已中止；支持原生继续时显示空输入继续按钮 | 继续成功或开始新轮次 |
| 已完成 | 绿色对号、已完成、实际时长与结束时间 | 新轮次开始 |
| 任务错误 | 显示错误原因；保留已产出内容和本地草稿 | 用户后续操作及真实状态更新 |
| 设备离线/重连 | 标明离线或正在重连，缓存内容可读，草稿可编辑 | 连接恢复并完成状态校准 |
| 会话 owner 不可用/被其他应用占用 | 显示针对该会话的原因和可用恢复操作；保留草稿 | 重新接入并收到可操作状态 |
| 操作回执不确定 | 显示正在核实；先同步结果，避免重复提交 | 回执、快照或明确失败 |

本稿建议：运行数量以设备提供的“尚未结束的活动会话”为准，等待回答/审批也计入；一个会话的子 Agent 不重复计入会话数量。设备离线时不拿旧快照当实时数量，保留离线标识。

远端保存采用“原值 → 提交中 → 成功值/失败原值”。界面上的拖动预览和待保存选项不能冒充远端保存成功。模型、权限等被 PC 或其他控制端同时修改时，重新读取真实值并提示变化，不静默覆盖。

重新接入优先使用现有恢复机制。刷新运行时展示影响范围和结果，不当作万能的会话重置；不因单个请求失败退出整个设备连接，也不自动结束另一端的任务以抢占写权限。

## 4. 设备、项目、会话导航与标题

### 4.1 选择、搜索与管理

- 继续保留设备 → 项目 → 会话层级，设备名称及在线状态始终可辨认。
- 按现有账号/服务器隔离规则记住上次设备；重启后恢复该选择。设备暂时离线时展示离线，不能无提示改选默认设备；已删除或不再可访问时说明原因。
- 侧栏搜索用于项目和会话导航，与文件搜索分开；搜索结果保留项目归属，退出搜索恢复先前展开状态。
- 项目菜单第一行保留完整目录与复制按钮；多根项目分别显示目录。复制成功/失败均有反馈。
- 保留现有新建项目、新建会话、重命名、归档和删除能力。运行中的会话管理限制沿用真实接口能力；目录删除与仅移除项目不能混淆，继续保留原有确认内容。
- 新建完成后进入真实创建的会话；失败仍停在原处，保留已填信息。
- 子 Agent 单独显示名称、任务和状态；只有可读取目标才提供进入操作，不能用子 Agent 数量替代设备的会话并行数。

### 4.2 橙色标记、背景与滚动标题

| 位置 | 运行时 | 结束后 |
| --- | --- | --- |
| 设备图标 | 橙色动画点；多个活动会话才显示数字 | 隐藏点和数字 |
| 收起的项目 | 标题前橙色动画点；多个活动会话才显示数字；浅色运行背景 | 恢复正常背景 |
| 展开的项目 | 隐藏项目橙点，保留运行背景；多会话数字放独立位置，避免再出现一颗项目点 | 清除运行标记 |
| 会话行 | 标题前橙色动画点；比项目更浅的运行背景 | 隐藏运行点和背景 |
| 主会话标题 | 固定橙点，文字区域单独滚动 | 隐藏运行点 |
| 每轮 Token | 前面显示橙色动画点 | 隐藏橙点 |

长标题只在溢出时滚动：起点停 2 秒，移动到末尾后额外约一个字宽，停 1 秒，再回起点；左右渐变遮罩。点和操作按钮位置固定。系统减少动态效果时不循环滚动，仍可查看完整标题。

### 4.3 使用量位置与口径

- 标题下方为当前会话累计 Token 和费用；项目名称旁为整个项目累计，不相互替代。
- 每轮 Token 行保留输入、输出、缓存命中，后接美元金额，随真实统计更新；该行金额不加“预估”字样。
- 处理时长前保留转圈；成功完成后为绿色对号加时长及“已完成”。结束时间放 Token 下方靠左，未结束不显示；取消点击消息时间切换结束时间的行为。
- 中止和错误使用对应文案，不套用绿色成功对号。
- 费用沿用官方 API 单价的估算口径并区分缓存；说明入口展示费率来源和统计范围。未知模型、缺失历史和部分费用保留未知/部分统计状态，不补成零；缓存和推理 Token 不重复累计。

## 5. 消息、活动记录与滚动

- 用户正文使用右侧浅色气泡；助手正文直接排版。代码、表格、链接、图片、视频/附件、现有网页预览和下载入口完整保留。
- 公开的进度说明与最终回复分层；连续工具活动合为摘要，点击展开命令、文件、可公开输出和耗时。工具失败单独标记，不将单次工具结束显示为整轮成功。
- 展开箭头、内容高度同步变化；收到增量时不重复播放整个组的入场动画。返回同一会话时保留本次使用期间的展开状态。
- 提供有效的复制、文本选择、代码复制操作。复制失败提供可操作提示，不能点击后没有反馈。
- 图片点击进入查看器，支持平台已有的缩放与保存；加载失败可重试。视频保留原文件播放/下载入口，浏览器不支持编码时明确说明并提供下载。
- 会话历史按需加载，明确区分“没有更早内容”和“加载失败/内容被截断”。加载更早历史保持当前阅读锚点。
- 用户在底部时跟随流式输出；上翻后停止跟随。新内容出现时显示回到底部入口，图片加载、工具折叠、打开键盘不强行跳到底部。
- 从文件、计划、设置返回恢复原位置；旋转屏幕和宽窄布局切换保持正在阅读的内容。
- 既有等待列表在确有遗留条目时仍可查看和操作；正常运行中发送走直接引导，不重新默认排队。

## 6. 输入、附件与发送动作

### 6.1 输入与草稿

- 单行胶囊输入，多行平滑增高，到达可用高度后框内滚动；附件在上方横向排列，单独移除。
- 草稿按服务器、账号、设备、会话隔离，切换回来保留文字、图片和文件；计划待执行标记也归该会话。退出账号后不向下一个账号泄露草稿。
- 上传回调只能修改最初所属草稿。发送成功仅清理本次提交的内容，不能清空等待回执期间新增的编辑。
- 当前保留范围为应用本次运行内的切换；浏览器刷新、杀进程后的附件恢复，以及跨设备同步草稿，不包含在本轮承诺中。
- 离线可继续编辑已有会话的本地草稿；选择附件需要上传时说明尚未上传，恢复后由用户发送，不自动补发。
- Web 保留 Enter 发送、Shift+Enter 换行，中文输入法组合输入不误发送；手机使用显式发送按钮和系统键盘换行。

### 6.2 主按钮动作

| 条件 | 图标/动作 |
| --- | --- |
| 空闲且无内容 | 发送不可用 |
| 空闲且有内容 | 向上箭头，开始新轮次 |
| 活动轮次且无内容 | 停止方块，请求中止当前轮次 |
| 活动轮次且有内容 | 向上箭头，直接引导当前轮次 |
| 已中止、无内容且支持原生继续 | 黑色圆形内向右三角，继续原轮次 |
| 已中止但有新内容 | 按现有逻辑开始新轮次，文案与空输入继续区别明确 |
| 附件未就绪、提交中或回执待核实 | 显示实际进度，阻止重复提交；停止按钮不被上传进度永久遮住 |

停止、引导和继续均使用真实命令及轮次 ID。状态在点击前发生变化时，先校准，不把发给旧轮次的操作悄悄改成新任务。“继续”不能替换为自动发送一条“继续”文本。

### 6.3 附件能力与错误

- `＋` 中提供相机、照片、视频、文件；按平台选择器及 Agent 能力显示有效入口。
- 图片最多 20 张，实际可用数量取 Agent 能力；旧 Agent 未声明新上限时沿用现有回退。超过数量在选择时提示，不等发送后被服务器拒绝。
- 现有普通文件和视频合计每次最多 4 个；普通文件上限 20 MiB，视频上限 512 MiB，仍需服从设备能力。此次“20”明确针对图片，不默默扩展为 20 个视频。
- 图片压缩和转换沿用有效链路；上传时显示状态，失败可重试，文件可移除；不把未上传资源视为已送达。
- 单文件失败只影响该项。移除时取消相关请求；取消选择器不改变已有草稿。大视频分块上传，不一次读取到常驻 JS/Qt 内存。
- 编码、文件大小、格式、无访问权限和连接错误分别反馈；文件名支持中文、空格和长名称。

## 7. 模型、强度、权限与模式

### 7.1 已认可的模型外观和动作

- 沿用网页第二版：270° 仪表轨道，蓝弧与指针位置同步；实际刻度数来自模型。六档第三档指向正上方。
- 快捷控件从仪表位置展开到输入区上方居中胶囊，输入区逐渐弱化，模型标题稍后出现；关闭时收回入口。
- 白球直径 40、蓝色轨道高度 48，蓝色覆盖白球并在右边缘多 4 像素，上下各 4 像素；最低和最高档也成立。
- 拖动连续跟手、文字实时预览，松开吸附后才发保存请求；点刻度和键盘调节具有相同结果。取消拖动不提交预览值。
- 高级设置保持参考中的分组行和向上选单，模型列表显示选中标记；不替换成另一套页面或多放一个不同表现的滑块。
- 正式版显示真实模型和可用强度；切模型后依照真实返回选择支持的档位，不硬编码六档，不保留已失效值。
- 模型未知、暂未同步、只支持一种强度时有清晰状态；不能擅自选一个示例模型代替。

### 7.2 设置保存与运行中修改

模型、强度、权限在 Agent 支持运行中修改时可选；不因任务处于活动状态笼统禁用。保存只表达之后实际生效的设置，不承诺重写已经生成的内容。

同一设置提交期间避免叠加冲突写入，显示保存反馈。若 PC 改了模型导致拖动期间可用强度变化，取消旧预览并加载新设置。失败保留草稿和会话，不关闭连接。

### 7.3 权限和方案模式

| 真实权限 | 入口与面板 |
| --- | --- |
| 请求批准 | 第二版的直立手掌 |
| 替我批准（`auto-review`） | 终端盾牌；仅调整显示名，保持真实权限语义 |
| 完全访问 | 橙色警告盾牌，保留既有确认 |
| 只读 | 眼睛 |
| 自定义 | 明确显示“自定义”，可查看真实限制摘要，不能假装选中了某个预设 |

入口位于加号之后，随真实选择更新图标、选中项和无障碍名称。当前值为自定义时，改成预设是一项真实变更；取消完全访问确认不改变原权限。

默认/Plan 工作模式继续按当前能力在空闲时切换。启用 Plan 后显示可移除标签；移除同样需要真实保存成功。高级设置的“速度”本轮不开放可操作入口，待完整协议支持后单独确定。

## 8. 分页问答与审批

### 8.1 问答卡片

- 顶部显示题号和总数，前后箭头翻页，中间为题目、选项及说明，底部提供来源允许的自定义答案；只有一题时不占用无效翻页按钮。
- 选项使用单选视觉；是否允许“其他”、是否为保密输入，依据问题结构。保密回答使用隐藏输入，不出现在普通调试日志。
- 翻页保留本地答案；返回会话仍能继续。答案按请求 ID、题目 ID 隔离；新请求不继承旧答案。
- 保留来源语义：异步问题按题提交；需要完整 RPC 答案时，最后一题满足条件后统一提交全部答案。卡片文案区分“下一题”和“提交”，不因只是翻页就发送。
- 已有选项点击即提交的异步问题继续明确反馈；待统一提交的问题只是选择，提交前可修改。
- 提交中显示进度；成功显示已提交并等待状态同步；失败保留答案可重试。PC 已处理或请求过期后停止远端回答，显示原因。
- 跳过仅在来源支持时出现，不添加自动计时提交。无可解析题目时提供原始可阅读说明与 PC 处理指引。
- 键盘出现时题目、输入框和当前提交操作仍可见，切页不会清空文本或触发误提交。

### 8.2 审批卡片

- 继续覆盖当前可回应的命令、文件、Browser/Computer Use 授权；只显示请求实际允许的决策与授权范围。
- 命令、目标、原因和范围可阅读；详情截断明确标记，不把缺少内容显示成空白批准卡。
- 允许一次、本次会话、始终允许等操作只在真实请求提供时出现。无法远程处理的权限/MCP/其他请求保留明确的 PC 处理入口说明。
- 重复点击、请求被另一端处理、断线和回执不确定均走共用状态规则；任务权限预设与单次请求的批准不是同一个操作。

## 9. 完整计划、执行步骤与准备执行

### 9.1 两类计划分开

| 内容 | 展示 | 数据依据 |
| --- | --- | --- |
| 执行步骤 | 当前活动中的步骤列表，待做/进行/完成 | `turn.plan` 等真实步骤状态 |
| 完整方案 | 标题、摘要渐隐、展开阅读、复制和导出 | 运行时明确的完整计划内容及稳定身份 |

不能把步骤清单当作最终方案，也不能把任意含“计划”标题的 Markdown 自动识别为可执行方案。已有计划类型/明确内容标记应保留到快照与历史；只有普通 Markdown 时先保证原样阅读。

完整方案流式生成时可以阅读，复制/导出注明当前内容；“执行此方案”仅在完整、可定位的方案完成后可用。历史方案仍能阅读，内容截断时先加载完整内容，失败不导出假完整文件。

### 9.2 卡片与阅读器

- 卡片展示标题、有限行摘要、渐隐、展开、复制和下载/分享入口；阅读器支持完整 Markdown、代码和链接。
- Web 下载 Markdown 文件，原生使用可用的系统分享/保存；取消分享不报操作失败，文件名使用可用标题。
- 打开和返回保持会话锚点，阅读器自身滚动与会话分离。

### 9.3 “执行此方案”已确认流程

1. 点击后回到输入框，为同一会话准备执行指令和可辨认的方案引用/标签，不发送命令、不立即切模式。
2. 输入框已有文字或附件时保留，执行指令追加为独立段落，不覆盖原草稿；重复点击同一方案不重复插入相同待执行内容。
3. 用户可继续补充或移除方案标签。移除标签取消本次待执行状态，不删除方案历史。
4. 用户主动发送时，先确认会话空闲；若需从 Plan 切默认模式，保存成功后再提交执行请求。切换失败保留草稿且不发送；切换成功而发送失败时说明实际模式已经改变，草稿仍保留。
5. 当前仍有活动任务时可以准备草稿，但该执行入口要等待任务结束或用户主动停止，不将执行方案偷偷作为当前轮次的引导，也不自动中断任务。
6. 设备离线、方案已失效或能力不足时保留草稿，说明原因。回执不确定先核实，不自动重发。

这里的“准备执行方案”使用用户可编辑的新任务输入；“中止后空输入继续”仍使用原生继续接口，两者在文案和操作上分开。

## 10. 项目目录、搜索、文件与差异

### 10.1 文件面板与来源

- 从会话更改胶囊进入时默认“已修改”；从项目“浏览文件”进入时默认“所有文件”。面板显示设备、项目和当前范围。
- “已修改”明确归属哪一轮；当前数据为该轮已观测的修改，可能截断，不标成整个仓库的完整 Git 差异。
- “所有文件”浏览当前所选项目的授权根目录；多根项目显示根目录选择或分组。目录树只展开用户需要的部分。
- 本轮提供查看、复制、下载及已有类型预览；不增加编辑、删除、移动文件、应用补丁、暂存或提交按钮。
- 两个页签分别记住搜索与位置，在同一项目内切换不丢；换设备/项目时清楚切换范围。

### 10.2 目录浏览

- 文件夹点击展开/收起；子目录按需请求，支持分页/继续加载。提供面包屑、返回上级和刷新。
- 默认目录在前、文件在后，名称稳定排序；建议默认隐藏 `.git`、依赖及构建缓存等常见忽略目录，提供“显示隐藏/被忽略项”开关，明确当前排除范围。
- 空目录、加载失败、无权限、目录已移走、离线分别展示；单目录失败可重试，不清空整个项目树。
- 浏览能力以设备和项目授权范围为边界；保留原有会话引用文件的读取规则，另建项目浏览通道。中文、空格、盘符、多根目录及链接边界在协议和 Qt 实现中统一处理。
- 授权随已有项目权限/会话身份校验；浏览不会自行扩大到整台电脑。能力不可用时显示需更新的组件与版本信息，不能只展示空白文件树。

### 10.3 文件名、路径及内容搜索

- 搜索框明确选择“文件名/路径”或“内容”；范围为当前项目/当前根目录，可从目录操作缩小到子目录。两种搜索都属于本轮功能。
- 文件名/路径结果显示匹配片段和相对路径；内容结果按文件分组，展示行号和前后文，点击跳转到源码对应位置并高亮。
- 默认按普通文本搜索，不加入未确认的正则语法。建议提供大小写匹配选项；沿用目录的隐藏/忽略范围，并能看到当前范围。
- 文本搜索跳过二进制及超出预算的大文件，明确报告跳过/结果受限状态；可读取这些文件并不意味着必须扫描其全部内容。
- 输入变化时取消旧查询，短暂合并连续输入；有结果数量/页数及时间预算，允许停止和继续加载。不在 Agent 常驻构建全项目索引，不一次上传项目内容。
- 新请求结果必须属于当前设备、项目、根目录和关键词；关闭面板或换项目取消请求，旧响应不覆盖新搜索。
- 搜索完成但无结果，与仍在搜索、部分结果、设备失联分别呈现。

### 10.4 差异与源码

- 差异显示文件相对路径、操作类型、增删统计、区块头、旧/新行号和增删背景；颜色外还有 `+/-` 标识。
- 当前轮次的累计更改按真实差异展示；同一路径多次修改不靠简单相加伪造 Git 统计。截断或未保存前后版本时明确提示可读范围。
- 已删除文件可读保存下来的差异；没有旧内容时不能假装能打开原始文件。
- 源码阅读器有语言高亮、行号、文本选择、复制、下载；长行横向滚动，大文件分段读取/按需渲染。搜索跳转不要求一次加载整个文件。
- 文件切换、源码/差异切换、返回结果列表各自恢复位置；新增内容改变行号时提示刷新，不跳到错误文件。
- 读取版本在下载/分段过程中变化时停止混合拼接，提示重新加载。无法识别的文本编码标注并提供原文件下载；二进制展示文件信息和下载，不当文本硬解码。
- 沿用现有大小与分块限制；过大文件解释限制，不为“复制全部”把不完整预览冒充完整文件。

### 10.5 会话文件与网页预览

- 会话内图片、视频、下载链接及本地网页预览继续使用已验证的资源和请求转发链路；项目目录浏览不替换这些引用。
- 本地文件不存在、未被会话引用、文件改变、服务器连接失败和不支持的类型给出不同提示及可用重试/刷新操作。
- 已支持的网页表单、相对资源、接口请求和登录交互需要回归；预览刷新不应被当成提交成功。
- 源码阅读和执行网页预览是明确分开的按钮；退出预览回到原会话，不启动外部任务。

## 11. 设置、主题与跨端同步

### 11.1 设置分组

| 分组 | 本轮行为 |
| --- | --- |
| 常规 | 保留现有偏好和通知相关设置；只展示当前平台有效项 |
| 外观 | 系统/亮/暗、强调色，兼容已有暖色皮肤；即时预览与可靠保存 |
| 服务器与设备 | 当前服务器、设备与连接状态、现有管理及运行时刷新能力 |
| 更新与下载 | 保留平台对应版本、检查、下载/安装入口及错误反馈 |
| 关于与版本 | 实际 Control、Agent 和服务器信息，复制诊断有明确反馈 |
| 微信 ClawBot 等既有入口 | 保留原功能及配置，不因样式改造丢失 |

设置搜索定位已存在的分组/设置项，没有结果明确显示；不复制参考应用的订阅、记忆等无效入口。窄屏分组列表和详情返回层次明确，宽屏使用分类加内容区域。

### 11.2 外观与保存

- 系统/亮/暗与强调色分别保存。亮暗切换立即覆盖消息、菜单、面板、工具、差异、预览外壳及平台可控的系统栏。
- 橙色运行、绿色成功、红色错误保持固定含义，不随强调色改变。
- 旧皮肤偏好迁移后保持可识别效果，读取失败回到有效默认值；本地保存失败要反馈，不能重启后无说明丢失选择。
- 本轮建议外观等个人偏好按本控制端持久化，不新增跨设备云同步；模型/权限等远端会话设置则依真实会话状态同步。

### 11.3 明确的保存边界

| 数据 | 规则 |
| --- | --- |
| 上次选中设备 | 本控制端重启后恢复，按账号/服务器隔离 |
| 主题与强调色 | 本控制端持久化 |
| 会话文字、图片、文件草稿 | 本次运行内切换保留，不承诺重启/刷新或跨设备恢复 |
| 问答尚未提交的输入、目录和阅读位置 | 本次运行内按请求/会话/项目隔离保留；过期内容标明失效 |
| 模型、强度、权限、任务状态、使用量 | 远端真实状态同步，PC 修改后控制端更新 |
| 蓝色未读状态 | 本轮暂缓 |

## 12. 动效、焦点与资源使用

- 主会话、模型和权限沿用已经认可的第二版视觉；其余页面与参考逐项核对，不只套相同配色。
- 小菜单从触发位置出现；底部面板跟手上滑/下拉，遮罩同步；计划和文件展开为阅读器，返回恢复原内容。
- 模型快捷面板以已认可的约 360 ms 展开、230 ms 收回作为调校基线；其余时长参照样式方案，最终以连续操作录屏核对。
- 键盘跟随系统避让，不覆盖输入、问答提交和菜单。关闭面板按操作恢复原焦点；Web 支持 Tab 循环、Esc 逐层关闭；系统返回先处理最上层交互。
- 面板滚动、滑块、代码横向滚动、图片缩放和文本选择优先，不误触侧栏；不在正在拖动滑块时顺带关闭面板。
- 大字体、小屏、亮暗、减少动态效果均保留可读性和可操作面积。状态除颜色外提供文字/图标说明。
- 循环动画只运行于可见的活动内容，离开页面、应用后台或任务结束后停止；不为模仿模糊效果增加大面积常驻实时处理。
- 历史、目录、搜索、文件与差异按需加载并限制缓存；关闭阅读器释放大文件/视频资源，取消旧请求，避免内存随浏览累计。

## 13. 新能力与兼容验收

| 范围 | 当前基础 | 正式开发需完成的工作 |
| --- | --- | --- |
| 会话/输入/模型/权限 | 已有真实命令和独立视觉样稿 | 接入真实数据、回执、冲突、能力及焦点管理 |
| 问答/审批 | 已有请求结构和来源区分 | 分页、答案保留、真实提交和过期状态 |
| 完整计划 | 运行时存在计划内容类型；当前主要展示步骤/普通消息 | 验证并保留稳定内容、快照/历史完整读取、准备执行流程 |
| 当前轮次差异 | 已有受限文件更改记录 | 保留范围/截断标记、完善阅读器；按实际数据补全读取 |
| 项目目录与搜索 | 当前没有完整远端浏览接口 | 协议、能力声明、Qt Agent 列目录/文本搜索/读取、Relay 转发、Control 页面与取消/分页 |
| 主题和设置 | 已有分组与皮肤 | 偏好兼容、真实保存、跨页面主题和平台适配 |

新增能力单独探测。旧 Agent 不支持目录搜索或完整计划时，说明缺失能力和升级途径，原有聊天、文件引用和连接继续可用。新增能力失败不能再次造成协议不兼容而断开整台设备。

功能与交互整体确认后，正式开发可分批交付，范围保持本稿一致。优先把主会话接入真实状态，再完善问答/计划/阅读器，最后交付目录搜索的端到端能力；需要新增远端能力的批次同步更新服务器和 Qt Agent。
