# 安全与配置

## 账号和任务权限

控制端账号控制远程访问，官方 Codex 账号/模型密钥控制本机执行。PC 和控制端同账号登录才可访问设备。后台管理员使用独立登录入口和用户名命名空间，只能管理账号与服务器，不能控制 PC。

密码由 Relay 使用加盐 scrypt 哈希；会话凭据以哈希存储。控制端与后台的会话按前台续期计算空闲超时，由管理员设为 1 分钟至 30 天，默认 7 天；PC Agent 保持 7 天固定有效期。服务端验证超时，后台心跳不续期，延长设置不恢复已过期登录。改密或禁用撤销该账号全部会话，退出只撤销当前会话。Agent 会话绑定单台设备，WebSocket ticket 短期且一次性。使用 HTTPS/WSS 保护账号、会话和任务内容。

既有任务沿用官方 Codex 的本机权限与审批。远程新建会话明确使用工作区写入（`workspace-write`）与按需审批（`on-request`）。程序不修改官方应用文件，不公开官方 IPC/App Server 端口，不复制用户 API key 到 Relay。具体适配仍是实验性兼容层。

新建/添加项目默认不授权目录，只能在 PC 连接器本地选择父目录并保存。控制端发送父目录标识与相对路径，Agent 在本机逐级检查目录真实路径、符号链接、目录身份及断开状态；拒绝越界、移动/替换的目录、Windows 设备文件名。授权只约束这个入口，不提供操作系统层面的文件隔离，也不能对抗已经拥有本机文件修改权限的其他进程。Codex 后续命令的范围仍由其执行沙箱和审批控制。授权父目录路径会同步给同账号控制端以便选择，脱敏诊断不包含路径。

服务器更新保持 Relay 非 root 运行。root 所有的更新器只读取版本请求，重新从固定 GitHub 仓库取 Release、校验 SHA-256、拒绝不安全归档，再切换程序。后台不接受命令或下载 URL，Docker 不挂载主机 socket。详见 [服务器更新](server-update.md)。

## PC 安全存储与进程边界

Electron 主进程使用 safeStorage：Windows 系统 DPAPI，macOS Keychain。`session.enc` 是加密会话，密码只在登录操作中暂存；存储不可用时拒绝登录持久化。读取失败需重新登录，不回退明文。

React 窗口启用 sandbox、contextIsolation、禁用 nodeIntegration；preload 仅开放固定的账号/连接/设置/诊断 IPC。主进程检查 sender/frame，设置用 schema 校验，拒绝任意导航/弹窗/权限申请。渲染器 CSP 禁止网络连接；网络与会话留在主进程/Agent。

音频播放沿用会话文件引用及版本检查，随机播放地址仅绑定一个账号登录会话、设备、会话和文件版本，30 分钟有效；不把长期登录凭据放进媒体 URL。每次读取重新验证会话和归属，改密/退出会撤销地址和进行中的读取，关闭播放器主动撤销。地址仅存于 Relay 内存，不进入快照、数据库或持久客户端状态。每个登录会话最多 20 个播放地址，全服务器最多 1000 个；音频与下载共用传输并发限制。原生播放外壳仅包含可信播放器及错误报告脚本，禁止本机文件访问和任意导航；音频内容仅交给媒体解码器。

服务器 `0.3.9` 的会话音频卡片按用户点击申请地址，和文件弹窗共用单个播放控制器，切换时停止旧播放器并等待其地址清理，迟到的创建结果也会撤销。音频文件登记只处理可见 Markdown 块中的音频嵌入标记，代码及链接定义中的标题文字不授予文件读取权限。

设置只保存服务器、账号名称、设备名、目录和偏好。普通导出诊断不会包含这些字段、会话或密码。日志只接收符合格式的诊断代码，原始 adapter stdout/stderr 不转发到 UI。退出登录也保留本机任务所需的暂停 Agent，直到任务结束或用户退出程序。

原生控制端使用 SecureStore；Web 和后台采用不同 key 的 localStorage，旧 sessionStorage 登录自动迁移。保存的是会话凭据而非密码，页面重新打开仍须经服务端验证；网络错误不清除登录，401 才清除失效凭据。退出清理新旧存储，共享浏览器用完后应退出登录。浏览器存储不是操作系统凭据库，因此部署还应防止网页脚本注入并使用 HTTPS。服务器的初始化管理员配置是敏感文件，即便密码使用 Base64 编码，也不是加密。

用户主动添加的文件附件暂存在 Relay 数据目录的 `uploads` 中，与从 PC 按需转发的下载文件分开。每份附件绑定账号、设备和会话，控制端只能上传/移除，目标设备的 Agent 会话才能下载；文件字节不进入快照或数据库。每块最多 512 KiB，单个文件 20 MiB，预留磁盘配额为每设备 256 MiB、全局 1 GiB，最多 2000 份，24 小时后清理。附件下载强制二进制附件并禁用缓存和 MIME 猜测，不在 Relay 来源下执行 HTML/SVG。私有暂存目录和文件分别使用 0700/0600 权限。

PC 在独立附件目录使用随机 ID 和会话哈希隔离文件，处理危险文件名，核对大小与 SHA-256 后再交给 Codex。已发送或排队的本机副本保留供后续读取；Relay 的 24 小时过期不删除 PC 副本。添加文件不改变 Codex 的执行沙箱与审批权限。

## 源码、文档和发布包

不在源码、示例、文档、测试中写真实部署 IP、域名、密码或 session；示例使用 `example.com`/`.example`、127.0.0.1 或 RFC 5737 保留 IP。仅在本机忽略的配置输入真实地址。

`.local`、`.env`、构建产物和安装包被 Git 忽略。服务器打包和新仓库导出使用明确清单，排除 `.git`、本地配置、旧私有历史和历史 JSON 验证数据。`npm run check:docs` 检查文档链接及示例 IPv4；仍需发布前人工审核文件清单，特别是新增脚本/样例。

源码发布从干净导出创建新的 Git 根提交；旧工作区历史不会随导出进入新初始化的仓库。本地备份仅用于回退，旧公开信息的撤销或历史处理由仓库所有者处理。
