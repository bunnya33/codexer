# 安全与配置

## 账号和任务权限

控制端账号控制远程访问，官方 Codex 账号/模型密钥控制本机执行。PC 和控制端同账号登录才可访问设备。后台管理员使用独立登录入口和用户名命名空间，只能管理账号与服务器，不能控制 PC。

密码由 Relay 使用加盐 scrypt 哈希；会话凭据以哈希存储。控制端与后台的会话按前台续期计算空闲超时，由管理员设为 1 分钟至 30 天，默认 7 天；PC Agent 默认 7 天，管理员可独立设为 1–36500 天或永不过期。服务端验证超时，后台心跳不续期，延长设置不恢复已过期登录。改密或禁用撤销该账号全部会话，退出只撤销当前会话。Agent 会话绑定单台设备，WebSocket ticket 短期且一次性。使用 HTTPS/WSS 保护账号、会话和任务内容。

既有任务沿用官方 Codex 的本机权限与审批。远程新建会话明确使用工作区写入（`workspace-write`）与按需审批（`on-request`）。兼容的连接器支持用户在空闲会话中显式更改权限；完全访问另需界面确认。权限更改校验所见设置的指纹，使用固定官方策略与电脑上的工作区目录，等待官方有效设置确认，避免覆盖过期设置。程序不修改官方应用文件，不公开官方 IPC/App Server 端口，不复制用户 API key 到 Relay。具体适配仍是实验性兼容层。

Browser 网站授权和 Computer Use 应用授权只转发已识别的空表单访问请求，PC 再核对原始请求、会话、轮次和可选授权范围。只提供一次或官方明确提供的会话/持久授权，不提供所有网站通用授权；未知表单、登录挑战、受限或签名请求仍需在官方客户端处理。macOS 屏幕录制、辅助功能、钥匙串等系统授权仍由系统在本机确认。

新建/添加项目默认不授权目录，只能在 PC 连接器本地选择父目录并保存。控制端发送父目录标识与相对路径，Agent 在本机逐级检查目录真实路径、符号链接、目录身份及断开状态；拒绝越界、移动/替换的目录、Windows 设备文件名。授权只约束这个入口，不提供操作系统层面的文件隔离，也不能对抗已经拥有本机文件修改权限的其他进程。Codex 后续命令的范围仍由其执行沙箱和审批控制。授权父目录路径会同步给同账号控制端以便选择，脱敏诊断不包含路径。

服务器更新保持 Relay 非 root 运行。root 所有的更新器只读取版本请求，重新从固定 GitHub 仓库取 Release、校验 SHA-256、拒绝不安全归档，再切换程序。后台不接受命令或下载 URL，Docker 不挂载主机 socket。详见 [服务器更新](server-update.md)。

## 管理后台资源状态

`GET /v1/admin/system/resources` 只接受管理员会话，普通控制端账号和 PC Agent 无权读取。响应不缓存于浏览器，仅包含系统聚合计数、Codexer 自身进程占用及系统/数据目录分区的挂载点、文件系统和容量；不枚举其它进程，不返回文件列表、环境变量、主机名、账号或会话内容。采样在服务器按需共享短时缓存，不创建历史数据库或常驻监控进程。

## 离线设备数据清理

控制端删除离线设备只接受该设备所有者的普通账号登录，不能删除其它账号设备，管理员和 Agent 凭据不能调用。删除与 Agent 连接在同一设备串行通道内校验在线状态，在线设备拒绝删除。清理包含服务器快照、目录、事件、命令/结果、图片、上传附件、公开分享及设备关联的微信路由、偏好和收发记录；进行中的临时能力与订阅同时撤销。账号级微信绑定及其它设备的数据不受影响。

删除不是永久禁止连接：服务器保留设备/安装身份、删除标记和已有登录会话，设备从控制端列表隐藏且同步接口不可访问；仍有效的 Agent 会话再次连接后移除标记并重新同步本机数据。凭据过期、改密和账号禁用规则继续生效。不会删除 PC 文件或本机 Codex 会话，也不会恢复旧分享 key。数据库逻辑删除不等于覆写数据库空闲页、备份或已发送给访客的内容。

## PC 安全存储与进程边界

Electron 主进程使用 safeStorage：Windows 系统 DPAPI，macOS Keychain。`session.enc` 是加密会话，密码只在登录操作中暂存；存储不可用时拒绝登录持久化。读取失败需重新登录，不回退明文。

React 窗口启用 sandbox、contextIsolation、禁用 nodeIntegration；preload 仅开放固定的账号/连接/设置/诊断 IPC。主进程检查 sender/frame，设置用 schema 校验，拒绝任意导航/弹窗/权限申请。渲染器 CSP 禁止网络连接；网络与会话留在主进程/Agent。

音频播放沿用会话文件引用及版本检查，随机播放地址仅绑定一个账号登录会话、设备、会话和文件版本，30 分钟有效；不把长期登录凭据放进媒体 URL。每次读取重新验证会话和归属，改密/退出会撤销地址和进行中的读取，关闭播放器主动撤销。地址仅存于 Relay 内存，不进入快照、数据库或持久客户端状态。每个登录会话最多 20 个播放地址，全服务器最多 1000 个；音频与下载共用传输并发限制。原生播放外壳仅包含可信播放器及错误报告脚本，禁止本机文件访问和任意导航；音频内容仅交给媒体解码器。

服务器 `0.3.21` 的公开音频分享由用户显式创建，使用独立持久化分享 key 和有效期，创建者退出登录或关闭播放器不撤销它。每次回源仍检查有效期、账号/设备归属与源会话；仅允许读取绑定音频路径，禁用任意文件和历史请求。到期、停用或换 key 撤销进行中的读取和后续访问，已经送达访客的内容无法收回。公开页面不包含来源路径，文件名转义，媒体响应禁止缓存和 MIME 猜测；只转发文件，不将音频存入 Relay。

服务器 `0.3.22` 的公开音频下载复用同一授权、路径、版本和并发限制；只增加附件响应头及下载入口，文件名使用 UTF-8 编码。下载也受有效期、停用及换 key 控制。复制分享链接直接写入当前已显示的地址，无需联网，不重新授权或续期；剪贴板失败不报告成功。

服务器 `0.3.9` 的会话音频卡片按用户点击申请地址，和文件弹窗共用单个播放控制器，切换时停止旧播放器并等待其地址清理，迟到的创建结果也会撤销。音频文件登记只处理可见 Markdown 块中的音频嵌入标记，代码及链接定义中的标题文字不授予文件读取权限。

设置只保存服务器、账号名称、设备名、目录和偏好。普通导出诊断不会包含这些字段、会话或密码。日志只接收符合格式的诊断代码，原始 adapter stdout/stderr 不转发到 UI。退出登录也保留本机任务所需的暂停 Agent，直到任务结束或用户退出程序。

原生控制端使用 SecureStore；Web 和后台采用不同 key 的 localStorage，旧 sessionStorage 登录自动迁移。保存的是会话凭据而非密码，页面重新打开仍须经服务端验证；网络错误不清除登录，401 才清除失效凭据。退出清理新旧存储，共享浏览器用完后应退出登录。浏览器存储不是操作系统凭据库，因此部署还应防止网页脚本注入并使用 HTTPS。服务器的初始化管理员配置是敏感文件，即便密码使用 Base64 编码，也不是加密。

用户主动添加的文件附件暂存在 Relay 数据目录的 `uploads` 中，与从 PC 按需转发的下载文件分开。每份附件绑定账号、设备和会话，控制端只能上传/移除，目标设备的 Agent 会话才能下载；文件字节不进入快照或数据库。每块最多 512 KiB，单个文件 20 MiB，预留磁盘配额为每设备 256 MiB、全局 1 GiB，最多 2000 份，24 小时后清理。附件下载强制二进制附件并禁用缓存和 MIME 猜测，不在 Relay 来源下执行 HTML/SVG。私有暂存目录和文件分别使用 0700/0600 权限。

PC 在独立附件目录使用随机 ID 和会话哈希隔离文件，处理危险文件名，核对大小与 SHA-256 后再交给 Codex。已发送或排队的本机副本保留供后续读取；Relay 的 24 小时过期不删除 PC 副本。添加文件不改变 Codex 的执行沙箱与审批权限。

## 源码、文档和发布包

PC Agent 安装包仅管理员可上传/发布，普通控制端账号只能查询和下载，所有请求使用 Bearer 认证。安装包以随机 ID 存于私有 `agent-releases` 目录，原始文件名只作下载显示，不参与服务器路径；服务器校验体积和 PE 结构，计算 SHA-256，不执行上传内容。上传先写入临时文件，再原子替换发布记录，重新验证管理员会话后才发布；取消、超限或校验失败不改变当前安装包。下载强制二进制附件、禁止缓存及内容类型猜测；不把 EXE 作为站点脚本执行。文件结构校验不替代管理员对安装包来源和版本的确认。服务器升级保留此目录，备份需连同数据目录保存。

公开网页分享由所有者显式开启，固定随机 key 等同访问凭据，持有者不需要控制端账号。数据库保存 key 以便所有者再次复制；不把控制端登录凭据或私有预览状态交给访客。每位访客的临时预览和上游 Cookie 独立，HTML 使用不含 `allow-same-origin` 的不透明来源沙盒；访客不能发送 Codex 反馈或命令。分享网页的服务资源、API 和 WebSocket 都属于授权范围，不把入口页面路径当作服务内部的访问控制；服务自身的敏感操作仍应自行鉴权。

分享仍检查设备所有权、账号/设备是否撤销、源会话目录及 Agent 的来源授权。停用或更换 key 会撤销临时预览和进行中的转发；账号禁用/设备撤销也使链接不可用。退出某个控制端登录不撤销分享。固定 key 配有持久化到期时间：默认 30 分钟，可选 1 天或自定义 1 分钟至 365 天；每个公开请求均检查截止时间，到期撤销临时预览及 HTTP/SSE/WebSocket 转发。只有所有者显式创建、更新有效期或重新开启才续期，访问和服务器重启不续期。旧版无期限记录从原创建时间加 30 分钟迁移，不保留永久公开链接。访客临时预览最多 24 小时，有效期内可重新打开固定链接获取新预览。浏览器公开外壳在已知截止时间重新请求服务器，失效时移除网页；已下载或保存的内容无法追溯收回。响应禁止缓存、搜索引擎索引和 Referrer 转发；公开入口有请求频率及访客数量限制。HTML 文件分享仅按固定引用路径读取，不开放同目录其他文件；依赖本地服务在线，不提供静态托管或任意端口扫描。

不在源码、示例、文档、测试中写真实部署 IP、域名、密码或 session；示例使用 `example.com`/`.example`、127.0.0.1 或 RFC 5737 保留 IP。仅在本机忽略的配置输入真实地址。

`.local`、`.env`、构建产物和安装包被 Git 忽略。服务器打包和新仓库导出使用明确清单，排除 `.git`、本地配置、旧私有历史和历史 JSON 验证数据。`npm run check:docs` 检查文档链接及示例 IPv4；仍需发布前人工审核文件清单，特别是新增脚本/样例。

源码发布从干净导出创建新的 Git 根提交；旧工作区历史不会随导出进入新初始化的仓库。本地备份仅用于回退，旧公开信息的撤销或历史处理由仓库所有者处理。
