# 控制客户端功能

控制端使用 React Native，同一代码覆盖 iOS、Android 和 Web。生产网页打开服务器根地址 `/`；管理后台单独在 `/admin/`。App 安装及开发见 [移动客户端](mobile.md)。

## 登录、设备与项目

输入 Relay 根地址、普通账号和密码。生产 Web 默认当前服务器来源，App 手动填地址。PC 连接器使用同账号登录后，自动显示在设备列表中；无法看到其他账号的电脑，管理员也受设备归属限制。

先选择电脑，再选项目及会话。设备离线时可以查看已缓存目录/状态，但新控制、远程历史与图片需要在线 Agent。目录来自本机官方项目和会话记录；搜索与近期列表帮助定位。

Web 宽屏用固定侧栏，窄屏和 App 用抽屉。App 可从左侧边缘滑开；Web 输入框 Enter 发送，Shift+Enter 换行。切换项目不会改变本机工作目录配置；新会话使用所选项目根目录。

## 会话操作

项目旁加号创建会话。会话菜单支持重命名、归档和永久删除，原生端长按打开菜单。新建/管理操作经本机官方 App Server，需要兼容的 Codex 版本和权限。删除不可恢复，界面先确认；后台账号禁用则保留已有会话数据。

打开会话读取分页历史并接入实时快照；Web 点击“加载更早消息”，App 顶部下拉加载。每页历史及长输出有大小限制，截断标记表示展示限制，不代表完整文件导出。需要完整原始记录时在本机查看官方数据。

## 消息和任务

| 操作 | 行为 |
| --- | --- |
| 发送 | 空闲且 owner 可用时发起任务，结果确认后清除草稿 |
| 待发送 | 任务运行时加入本机队列，空闲后顺序启动 |
| 引导 | 将指定队列消息引导到当前活动 turn |
| 移除待发送 | 删除尚未发送或未确认的队列项目；发送中不能移除 |
| 停止 | 请求中断当前 turn；不删除会话 |
| 审批/用户输入 | 展示本机运行请求，响应使用明确的 request/turn 标识 |
| 模型/推理强度 | 空闲时修改，选项以本机官方 catalog 为准 |

命令采用唯一 commandId、epoch 和过期时间。accepted 说明中转已接收；succeeded 说明本机运行接口确认，不代表模型已经完成回答。unknown 或超时可能已执行，先查看实际会话，再决定重试，避免重复任务。

PC 主动断开时停止接收新远程指令，已经开始的任务继续，队列自动发送暂停；PC 明确重新连接后恢复。停止整个 PC 连接器与“断开”行为不同，见 [PC 按钮说明](pc-setup.md)。

## 内容、图片与用量

Markdown 支持代码、任务列表、复制、命令/差异折叠，以及按顺序显示的活动记录。用量展示输入、输出与缓存命中；数据来自官方运行通知/本机日志，可能存在未观测区间。

图片可选择上传；Web 支持粘贴和拖放。App 按需转换 HEIC/压缩图片；上传失败保留草稿以便重试。原生查看器支持双指缩放、拖动、点击关闭；Web 支持缩放按钮和指针交互。图片通过认证接口取回，不生成公开访问链接。

## 登录持久化和故障

App 会话在 SecureStore，Web 会话在当前标签页 sessionStorage。密码不保存。退出登录撤销当前控制端会话，与其他设备会话相互独立；账号改密或禁用则撤销该账号全部会话。网络中断自动重连并同步 epoch/seq。

“等待 PC Agent”先检查 PC 是否同账号且已连接；“正在接入”检查本机 Codex、目录、owner 和版本；“需要重新登录”通常是会话过期、改密或禁用。详细排查见 [运维](operations.md)。
